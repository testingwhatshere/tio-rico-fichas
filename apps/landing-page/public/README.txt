📱 APK File Location

Coloca el archivo APK aquí:
- Nombre: tio-rico-fichas.apk
- Ubicación: apps/landing-page/public/tio-rico-fichas.apk

Cómo obtener el APK:
1. cd apps/chat-app
2. eas build --platform android --profile production
3. Esperar ~10-15 minutos
4. Descargar desde EAS Build dashboard
5. Copiar aquí: cp ~/Downloads/build-*.apk apps/landing-page/public/tio-rico-fichas.apk

Una vez que tengas el APK aquí, la landing page estará lista para deploy!
